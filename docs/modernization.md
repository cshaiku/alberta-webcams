## Image delivery

The private archive keeps original JPEGs unchanged. The image endpoint generates bounded 400, 640 and 840 pixel WebP derivatives and caches them privately. It never enlarges a source. Picture markup advertises only candidate widths that fit the original image. The JPEG remains a real fallback and is available in the viewer. Width and height attributes, fixed image boxes and object-fit contain preserve layout and the source’s embedded timestamp. The first image is eager and high priority; later images are lazy. A media test verifies format, proportional resizing, no upscaling, original preservation and rejection of arbitrary sizes and traversal.
